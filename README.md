# TET for Magpie

Magpie 的 TET 中转供应商插件，支持 GPT-5/6 模型发现、OpenAI Responses 转发、余额与用量查询。无运行时依赖，无需构建。

## 安装

在 Magpie 插件页面添加：

```text
github:xgxg-mdl/magpie-tet#main
```

或使用 CLI：

```bash
magpie plugin add github:xgxg-mdl/magpie-tet
magpie plugin login tet
```

## 使用

在 **TET** 供应商中填写 **API base URL** 和 **API Key**，随后选择 `tet/<模型 ID>`。

填写站点地址（如 `https://relay.example`）时自动使用 `/v1`；也可填写完整 API 地址，已有 `/v1` 或自定义路径会保留。建议使用 HTTPS；HTTP 会明文传输 Key 和请求内容。

插件通过 TET 中转站的 `/models` 获取模型、`/responses` 转发请求、`/usage` 查询余额与用量。目前支持 GPT-5/6 文本模型，不支持 Claude/Gemini 专用协议、图片生成、音频或实时模型。

供应商设置中的 **Show traffic statistics** 可控制流量统计展示。

### 管理台分组额度

需要查看管理台的周期额度时，登录方式选择 **TET API Key + 管理台额度**：

1. 填写网关 API 地址和独立的管理台地址，后者不是网关 API 地址。
2. 输入管理台账号和密码，无需选择或固定绑定分组。
3. 填写该登录项使用的 TET API Key。

每次刷新重新获取管理账号可见的全部分组及关联上游，跟随分组新增、删除、改名与上游迁移。旧认证中的固定分组字段会被忽略，有效会话无需重新登录；零分组也可以正常登录和查看钱包。

插件使用原生扁平双列窗口：消费统计在前，各分组先展示「并发」和可用重置，再展示 `5h` 和 `7d`，流量在后。单分组名称放在账号方案标签中，不显示上游内部编号；多分组通过指标名称前缀区分。多个上游的额度分别显示，优先采用可读名称，缺少或重名时才使用上游编号，不累加百分比或重置次数。分组没有上游时保留并发并显示「暂无额度来源」。到期提示附在重置次数下方，由 Magpie 按界面时区显示。真实的 Key 和订阅限额仍保留并优先展示。

管理台数据属于登录用户可见的来源，不代表当前 Key 的独占额度或实际路由归属。并发是最近一次读取的整个分组快照，可能包含其他 Key 的请求；周期额度和重置次数按上游读取，均仅供展示，不参与路由。金额和请求数完整显示，Token／TPM 使用紧凑格式。不会导入管理台已有的历史趋势；宿主协议没有独立的指标来源 ID 或历史清理接口，来源变化后的原生历史曲线隔离不作保证。

管理台数据随现有用量刷新读取，不额外轮询。单轮请求量为「分组列表页数 + 2 × 不同上游数」，不含登录和独立的钱包查询。同一管理会话的同时刷新共享整轮在途请求，跨分组的相同上游只读取一次；最多同时查询两个上游（四个 HTTP 请求）。列表分页和后续上游查询共用最多 5 秒的总预算。查询完成后不跨刷新缓存，列表失败不显示旧分组，上游查询失败仅影响该项；并发缺失或上限无效时不推断为零或无限。进度条可能漏掉两次刷新间的瞬时峰值，也不代表请求成功率。

密码仅用于登录，不保存；管理台会话保存在该账号的宿主认证数据中。会话过期后，重新使用此方式登录。管理台查询失败不会将有效的 API Key 标为过期，也不会隐藏正常的钱包和消费数据。改回 **TET API key** 登录方式可移除管理台绑定。

管理台接口按上游账号查询额度，列表的分组 ID 不能直接当成查询 ID。插件内部使用最新列表返回的上游 ID 查询，不将内部查询标识当作单上游场景的可见标签。同一来源可能被多个 Key 的登录项重复展示，不能将这些显示项理解为多份独立额度。

已过重置时间的非零读数、降级或超过 15 分钟未更新的额度读数仅显示状态，不生成百分比历史点。新读取明确返回零用量时仍显示 `0%`，但移除已失效的重置时间及周期推算；缺失读数不会补零。重置次数为零会明确显示。管理台用量查询最多等待 5 秒（配置的查询超时更短时采用更短值），超时以辅助状态展示，保留已成功读取的钱包和消费。此模式需要支持动态登录问题和密码问题的 Magpie；无需管理台数据的账号继续使用原登录方式。

## 配置

一般无需额外配置。高级选项在 Magpie 插件包的 `options` 中设置，修改后重载插件：

| 选项             | 默认值  | 用途                               |
| ---------------- | ------- | ---------------------------------- |
| `queryTimeoutMs` | `15000` | 模型及用量查询超时，单位毫秒       |
| `showTraffic`    | `true`  | 流量统计开关初始值                 |
| `excludeModels`  | `[]`    | 按模型 ID 隐藏模型                 |
| `modelOverrides` | `{}`    | 配置模型名称、容量、能力和推理档位 |

模型目录不保证所有能力可用。插件优先采用显式配置和宿主已有信息，未知能力默认不声明；已核实模型的配置示例见维护文档。
